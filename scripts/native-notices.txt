License: MIT, BSD-3-Clause, CC0-1.0 and public domain (see each notice)

The database engine inside better-sqlite3-multiple-ciphers (the native file
better_sqlite3.node) is compiled from the SQLite3 Multiple Ciphers
amalgamation, which contains SQLite and the components listed below. Their
notices are reproduced here. Hand-maintained in scripts/native-notices.txt;
check it against deps/sqlite3/sqlite3.c when better-sqlite3-multiple-ciphers
is upgraded.
